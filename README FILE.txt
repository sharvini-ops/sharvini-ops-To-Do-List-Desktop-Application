 ✅ Java To-Do List App

A simple and user-friendly **To-Do List Desktop Application** built using **Java Swing**.  
It helps users add and remove daily tasks efficiently with a minimal UI design.

---
 ✨ Features
- ➕ Add new tasks
- 🗑️ Remove selected tasks
- 🧾 Clean and simple GUI
- 🪟 Works as a standalone desktop app (JAR supported)

---

 🛠️ Technologies Used
| Component            |  Technology      |
|--------------------- | -----------------|
| Programming Language | Java (JDK 8+)    |
| GUI Framework        | Swing            |
| Data Structure       | DefaultListModel |
